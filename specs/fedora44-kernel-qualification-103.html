Acceptance and limits

This qualifies signed installation, native AMD64 kernel boot and kernel-only rollback under emulation, module loading and preserved host guards. It does not qualify an OS release migration, interrupted RPM recovery, K3s/Cilium/CSI data operations, GPU/firmware, Secure Boot, production hardware, service availability or protected data recovery. In particular, loading RBD/Ceph modules does not prove authentication or CSI attach, mount, read/write, snapshot, recovery or key-rotation behavior. Those independent tests remain open.
