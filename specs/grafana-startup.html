Cause and desired state

Grafana's service-account service attempts its migration once during Run; the subsequent ticker updates statistics and does not retry that migration. The server-lock implementation opens a database transaction while dashboard provisioning also writes SQLite. Limit Grafana's database connection pool to one connection so this single process serializes database writers. This is a connection-pool change, not a schema, credential, authorization or journal-format change. It can reduce concurrent access to Grafana's own metadata database; datasource query execution is separate. Set readiness initialDelaySeconds to 15, exceeding this observed approximately seven-second main-container initialization; keep recurring readiness and liveness checks enabled.
