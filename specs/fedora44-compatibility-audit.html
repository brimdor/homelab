Kickstart disk and root
kickstart.ks.j2		 clearpart --all, fixed EFI/root partitions and a remaining-space partition created with raw disk commands are destructive. Disk errors are suppressed with || true; %post --erroronfail cannot detect those suppressed failures. Exclude this path from maintenance. A future fresh installation needs an independently approved exact-disk plan, explicit partition identities and verified failure handling. Never invoke it as upgrade recovery.
Kickstart post-install context %post lacks --nochroot, yet creates paths under /mnt/sysimage and chroots there again. Pykickstart documents that ordinary post-install scripts already run in the installed-system chroot. The script's comments conflict with the documented execution context. Correct the context and prove SSH/hostname behavior in an isolated future installation before declaring fresh-install readiness.
Kickstart packages and security #version=RHEL8, @^custom-environment, a DVD-derived repository, disabled SELinux and disabled firewall remain declared. Fedora's Anaconda DNF5 change targeted Fedora 43; older installer behavior cannot be assumed for 44. Validate the exact Fedora 44 parser, package environment and repository metadata in an isolated installation. Review the security policy explicitly. A version comment or YAML syntax pass proves neither acceptance nor security.
